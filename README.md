# Bulk-cancellation-of-production-orders-and-cancellation-of-settlement

生产订单批量取消 TECO & 取消结算。

- **程序名**：ZPP024
- **REPORT 对象**：`zppc009`（注释块内程序名为 **ZPP024**，即 `ZPP024 ↔ zppc009` 映射）
- **模块**：PP（生产计划）
- **源码位置**：`src/zppc009.abap`

## 功能说明

通过调用事务码 CO02（BDC 方式），对选中的生产订单批量执行以下操作：

1. **取消技术完成（TECO）**：将已技术完成的生产订单撤消技术性完成
2. **取消关闭（结算）**：取消生产订单的完成/结算关闭状态

处理结果以 ALV 形式展示（生产订单、状态图标、消息类型、消息文本），支持双击跳转 CO03 查看订单，并对无错误的记录批量更新。

## 选择屏幕参数

| 参数 | 说明 |
|------|------|
| `S_AUFNR` | 生产订单号（可多选，支持从 Excel 模板批量导入） |
| `G_R1` | 取消 TECO |
| `G_R2` | 取消关闭（结算） |

选择屏幕上提供「下载模板文件」功能按钮，可下载批量导入模板。

## 运行前提

- 已维护生产订单（`CAUFV` 表）
- 具备事务码 CO02 的授权

## 部署步骤

1. 使用事务码 **SE38** 创建程序，将 `src/zppc009.abap` 源码粘贴保存并激活
2. 运行程序，输入生产订单号并选择操作类型（取消 TECO / 取消结算）
3. 在 ALV 结果中确认处理状态，选择「批量更改」执行
